# Example data

`Low_R_Test_10ohm_20251218_163101_IV.dat` is an I-V sweep of a 10 ohm test resistor recorded with the Keithley 6221 + 2182 I-V module (`pica/keithley/delta_mode/IV_K6221_DC_Sweep_GUI.py`). It shows the data-file layout: `#` header lines, then a column-name row, then comma-separated data. This file has an older single-line header; current modules write more header lines (program version, date, instrument addresses and sweep settings). Open it with the PICA Plotter Utility or any CSV reader.
